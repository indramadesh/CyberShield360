# Changelog — CyberShield360 Browser Protection

The packager (`npm run package`) reads the bullet points under the current
version's heading and publishes them as release notes on the website's
Browser Protection page. Keep each bullet to one line.

## 1.4.0
- Redesigned popup: the current site's status up front (shown straight away when the page was already checked automatically), plus Scan Link / Scan QR / Scan Text / Settings tiles
- Redesigned block page with risk level, category and confidence, and a View Details link to the full report
- New emerald look that matches the CyberShield360 web app (popup, settings and warning page)
- Risk levels now use drawn icons instead of emoji, always paired with a text label
- New toolbar icon
- Animations are turned off when your system asks for reduced motion

## 1.3.0
- Automatic and manual modes, each with its own on/off switch
- Scan links, messages, emails, QR-code images, screenshots and websites from the popup
- Pages at or above the block threshold (default 50) are blocked; lower-risk pages show a details notification
